02 // Build something real

The reference becomes useful when it leaves the reference site.

Studio projects keep content separate from presentation. You can change the active system without rewriting the page, then export the selected language as a clean website.

MVP
Working project mode

Start with a brief, not a blank canvas.

Name the project, choose a system, and begin from a semantic page structure. Add sections from a controlled library, write into explicit fields, move sections through document order, and preview the complete result at realistic viewport widths.

Every change is stored locally. Named versions preserve meaningful checkpoints. The export contains the pages, shared stylesheet, local fonts, project manifest, and a concise handoff note—with no Edit Mode controls.
