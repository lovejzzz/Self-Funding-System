02 // The product boundary

This is a reference instrument, not a website builder.

SYSTEMS/38 is designed to sharpen visual judgment and make design-system thinking transferable. It does not try to replace the tools, engineering stack, content model, or governance process a real organization already needs.

REF
Use the logic, not the shell

A recipe should teach a company how to think.

Each system documents the relationships that create its identity: type roles, semantic color pairs, density, grid, composition, component anatomy, interaction states, motion grammar, data language, responsive behavior, accessibility gates, and release governance.

Use those decisions as a rigorous visual reference, then recreate the system in the technologies and organizational conditions that fit the actual product. The value is not generated HTML. The value is a clearer eye, a shared vocabulary, and a coherent set of decisions.
