01 // The proposition

Free AI should not mean someone else is quietly paying the bill.

Today’s AI economy is one-directional: a human pays, the model spends. We close the loop. Intelligence creates economic value, then uses a fraction of that value to purchase its own compute.

01
The economic loop

Turn intelligence from a cost center into productive capital.

An agent that can code is already capable of creating digital value. Give it a treasury, payment rails, deployment tools, and an explicit cost model, and something changes: inference becomes investment.

The agent can decide when a local model is sufficient, when a frontier call is worth the price, and when building a reusable software asset is more valuable than completing another one-off task.

02 // Operating system

One closed loop. Four responsibilities.

Earn. Allocate. Buy intelligence. Build more capability. The system survives only when that loop creates more value than it consumes.

01 // EARN

Sell useful work

Code services, APIs, migrations, reviews, software assets.

02 // TREASURY

Allocate capital

Maintain runway, margins, reserves, risk limits.

03 // SPEND

Buy intelligence

Route work across local, open, and premium models.

04 // BUILD

Compound capability

Deploy services that can earn again without rebuilding.

04 // Why now

The missing pieces are finally becoming ordinary infrastructure.

Open-weight models, agentic coding harnesses, programmable wallets, machine payments, serverless deployment, and model routing have all become composable. The unsolved research problem is no longer “can an agent spend money?” It is “can an agent reliably earn more than it spends?”

05 // The experiment

Start with twenty dollars.

No grand claims. Give one agent a small treasury and a narrow mandate. Do not replenish it. Measure whether its runway dies, stabilizes, or compounds.
