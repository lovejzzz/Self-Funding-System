V0.1 scope

Build

  • Prepaid fixed quote
  • Hard model and execution budget

  • Double-entry financial ledger

Do not build
  • General autonomous job hunting
  • Open-ended production deployment
  • Self-modification
  • Unbounded wallet authority
  • Multiple services before margin proof
  • A new foundation model

Resource-rights schema

Postgres // typed, issuer-bound capacity
resource_rights(
  id, issuer_id, holder_id,
  resource_type, native_unit, quantity,
  scope_json, conditions_json,
  issued_at, starts_at, expires_at,
  revocable, revoked_at,
  transferable default false,
  cash_equivalent_minor default null,
  status
)

right_redemptions(
  id, right_id, request_hash,
  provider_request_id, usage_native,
  provider_evidence_hash, status,
  created_at
)

right_events(
  id, right_id, event_type,
  payload_hash, observed_at
)
Do not post unlike rights into balanced cash entries. Validate issuer authority, holder control, scope, expiry, revocation, and provider fulfillment separately. A signed credential is evidence of an issuer statement—not proof that the resource exists or was delivered.

The critical request path

01

Quote

Validate the request, hash canonical input, estimate model plus sandbox cost, and return a short-lived fixed price.

POST /v1/quotes
02

Fund

Verify payment authorization, create a pending revenue transaction, and reserve the maximum permitted job cost.

POST /v1/jobs
03

Run

Worker claims the job, chooses a model within budget, executes in a fresh sandbox, and records exact usage.

worker.claim → router → sandbox
04

Verify and settle

Acceptance tests must pass before settlement. Failed work releases unused reserve and follows the refund policy.

verify → book costs → settle revenue

Definition of done

NOW 0 · control plane

  • Every fixture declares RAIL_SANDBOX, TRANSPORT_INJECTION, or POLICY_INJECTION; no synthetic record can become an external observation.
  • A duplicate request or webhook cannot double-charge, double-book, or double-settle.
  • A crashed worker can safely resume or release the job.
  • A job can never exceed its recorded cost ceiling.
  • Every injected exception produces the specified freeze tier without erasing prior evidence.
  • All fixture transactions balance with zero unexplained difference inside their declared simulated boundary.

NOW 1 · live evidence

  • Every successful result has verifiable artifacts.
  • A minimum real charge or refund, standard automatic payout, itemized report, provider cash document, and bank evidence complete one independent close.
  • Only that complete chain may reach REVIEWED_CLOSED_LIVE; a sandbox payout, manual payout, or synthetic zero cannot substitute.
  • Ten consecutive accepted jobs produce positive contribution.
